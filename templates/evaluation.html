How these numbers are measured

Ranking depth
Each method returns its top {{ evaluation.config.depth }} answers. Correct answers outside that list count as misses.
Correct answers
A question can have several official answers ({{ evaluation.config.avg_relevant | round(2) }} on average in this split).
Why P@10 looks low
With {{ evaluation.config.avg_relevant | round(2) }} correct answers per question, P@10 cannot exceed about {{ '%.2f' | format(evaluation.config.avg_relevant / 10) }}. Compare methods with each other, and use recall, MAP and nDCG for the fuller picture.
Hybrid RRF
Fuses the three top-{{ evaluation.config.rrf.depth }} lists with k = {{ '%g' | format(evaluation.config.rrf.k) }}.
Settings
BM25 k1 = {{ '%g' | format(evaluation.config.bm25.k1) }}, b = {{ '%g' | format(evaluation.config.bm25.b) }}. Semantic model: {{ evaluation.config.model }} on {{ evaluation.config.device }}.
